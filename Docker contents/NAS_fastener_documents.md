# 1/4-inch NAS1352 screws and NAS620 washers

Downloaded complete, unmodified source PDFs on 2026-10-08 from Australian Aerospace Engineering's public specification library.

## Screw specification

- File: `NAS1352_socket-head_cap_screws_specification.pdf`
- Source: https://www.aaestore.com.au/media/specs/NAS1352.pdf
- NAS1352 revision 11 (2009); complete downloaded PDF contains 6 pages, including an additional scanned page after the 5 numbered standard sheets.
- PDF page 1, Table I: size code **4**, **.2500-20** thread (1/4-20), body diameter, head diameter/height, socket size, and other dimensions.
- Subsequent sheets contain strength, length, material, finish, and part-number requirements.

## Washer specification

- File: `NAS620_reduced-OD_flat_washers_specification.pdf`
- Source: https://www.aaestore.com.au/media/specs/NAS620.pdf
- NAS620 revision 8 (2013); all 3 sheets included.
- PDF page 1, Table I: 1/4-inch washers use size codes **416** and **416L** (light series). Listed inside diameter is **.255 inch**, outside diameter **.468 inch**, and nominal thickness **.063 inch** (416) or **.032 inch** (416L). Apply the table tolerances and sheet 3 notes.
- PDF page 2: material and finish requirements/codes. PDF page 3: part-number examples and notes.

These are historical standard copies, not verified as the latest revisions. Screw length, material/finish, and washer material/light-series choice were not specified; the full documents retain those options. No hardware suitability or qualification assessment was performed.
